# Pricing and Subscription Plans

OpenOCR offers three transparent tiers:

## 1. Free Explorer ($0 / month)
- 250 monthly page credits
- 1 concurrent extraction
- Up to 10MB file size (5 pages max)
- Web playground access (API key generation disabled)

## 2. Developer Pro ($49 / month)
- 10,000 monthly page credits ($0.005 / extra page)
- Full programmatic API keys with 300 req/min
- Up to 35MB file size (50 pages max)
- HMAC webhooks and asynchronous job queues

## 3. Enterprise Self-Hosted ($499 / month)
- 100,000 monthly cloud credits or unlimited air-gapped VPC deployment
- Priority SLA (S1 response target)
- Direct S3/MinIO signed storage uploads (up to 100MB)
- Dedicated engineering support
